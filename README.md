# Fruit Slice

A tiny, self-contained fruit-slicing toy for Android — pure Kotlin, custom
`View` rendering, zero third-party dependencies, no network access.

Slice fruit as they fly across the screen. There are no bombs, no lives and
no game over: it is a relaxed little toy you can play for thirty seconds or
thirty minutes.

## Features

- Pure Android framework APIs + Kotlin stdlib — no Jetpack, no libraries
- Custom `View` game loop driven by `Choreographer` (sprites, juice
  particles, slice trails, screen shake)
- 20+ hand-tuned fruit color palettes
- Synthesized sound effects generated by `scripts/gen_sounds.py`
  (pure-Python, stdlib only — regenerate any time); `pop/slice/cheer.wav`
  are fully script-generated, while the two short `timer_notice*.wav`
  voice prompts were produced with a TTS tool
- Immersive fullscreen, portrait-only, survives rotation / dark-mode / resize
  without resetting the game
- minSdk 21 / targetSdk 33

## Building

Open the project in Android Studio (Hedgehog or newer) and run, or build from
the command line with a local Gradle 8.x install:

```bash
gradle assembleDebug
# APK: app/build/outputs/apk/debug/FruitSlice-debug.apk
```

Install on a device:

```bash
adb install -r app/build/outputs/apk/debug/FruitSlice-debug.apk
```

### Release signing (optional)

Release builds are unsigned unless you provide a keystore. Copy the template
and fill in your own values — both files are git-ignored:

```bash
cp keystore.properties.example keystore.properties
```

```properties
RELEASE_STORE_FILE=keystore/your.keystore
RELEASE_STORE_PASSWORD=...
RELEASE_KEY_ALIAS=...
RELEASE_KEY_PASSWORD=...
```

## Project layout

```
app/src/main/java/com/alair/fruitslice/
  GameView.kt        # game loop, physics, rendering
  MainActivity.kt    # fullscreen host + reminder-notice playback
  SplashActivity.kt  # brief "Created By Alair" splash
app/src/main/res/raw/   # sound effects (wav)
scripts/gen_sounds.py   # regenerates pop/slice/cheer wav files
```
